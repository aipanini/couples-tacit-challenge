# 情侣默契大挑战 · couples-tacit-challenge

一个**无后端、单文件、可免费静态托管**的情侣小游戏：一个人设暗号 → 加密生成分享链接 → 另一个人经链接进入，输入猜测，实时看到和对方「多少位一致」。

## 玩法

- **出题方**：输入一串只有两人懂的暗号，点「生成链接」，得到**两条链接**——
  - 🔒 **挑战链接**（不含答案，发给 TA）
  - 🔑 **带答案链接**（含明文答案，自己留着防忘）
- **作答方**：点开链接，输入自己心里的那串字符，圆点逐位实时标记——一致绿、不一致红。点眼睛只能看**自己那一行**。
- **胜利**：猜测与暗号逐位全中，弹出「🌟 超越了这个星球上 99% 的情侣」。

## 本地运行

直接用浏览器打开 `index.html` 即可。**注意**：加密依赖安全上下文，请用 `https` 链接或 `localhost` 打开（直接双击 `file://` 可能被浏览器限制）。

## 部署到任意静态托管

把 `index.html` 传上去就行，零依赖、零构建：GitHub Pages / Vercel / Netlify / CloudStudio 均可。

## 技术 & 隐私

- 纯客户端 Web Crypto（`HMAC-SHA256`），**暗号不上传任何服务器**。
- **挑战链接** `#c=` 只装逐位哈希与密钥，作答方拿不到明文（只能离线逐位枚举——娱乐场景可接受）。
- **带答案链接** `#a=` 含明文答案，仅供你自己留存，**千万别发给对方**。
- 挑战链接采用紧凑 `v:2` 格式（HMAC 截断到 8 字节），较长暗号链接也比初版短约 70%。

## 链接格式（简述）

| 类型 | 片段 | 说明 |
|---|---|---|
| 挑战链接 | `#c=` + base64(`{v:2, n, k, h[], s, t}`) | 只含哈希，发给 TA |
| 带答案链接 | `#a=` + encodeURIComponent(暗号) `[&s=1]` | 含明文，自己留着 |

- `n`=位数，`k`=随机密钥，`h`=逐位 HMAC（8 字节/位），`s`=是否区分大小写，`t`=字符类型提示。
